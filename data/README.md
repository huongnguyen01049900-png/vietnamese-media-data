# Data snapshots

Các file `*.json.gz.b64` là snapshot nén được sinh từ workbook nghiên cứu ngày 2026-09-05.

Website dùng chúng để dựng lại workbook ngay trong trình duyệt, phục vụ GitHub Pages mà không cần backend.

- `source-detail.json.gz.b64`: 56 nguồn truyền thông
- `creator-detail.json.gz.b64`: 88 creator/blog/kênh cá nhân
- `added-magazines.json.gz.b64`: 11 tạp chí/ấn phẩm bổ sung
- `coverage-gaps.json.gz.b64`: các quốc gia/khu vực còn khoảng trống
- `taxonomy.json.gz.b64`: bảng phân loại nguồn
